1. Mengapa branch diperlukan?

Branch diperlukan untuk menyediakan ruang kerja mandiri yang terisolasi dari lini utama kode proyek. Dengan adanya branch, pengembang dapat bebas mencoba eksperimen, menambah fitur baru, atau membenahi kesalahan tanpa khawatir akan memengaruhi, merusak, atau mengganggu stabilitas kode yang sudah berjalan lancar di proyek utama.

2. Apa keuntungan bekerja pada branch dibanding langsung di main?

Keuntungan utama bekerja di branch terpisah dibanding langsung di branch main adalah terhindarnya risiko kerusakan pada sistem yang sudah stabil. Kode di branch main dapat selalu dijaga dalam kondisi bersih dan siap dirilis kapan saja, sementara para pengembang dalam tim bisa bekerja secara paralel di branch masing-masing tanpa khawatir kodenya saling bentrok atau menimpa satu sama lain.

3. Kapan sebaiknya membuat branch baru?

Pembuatan branch baru sebaiknya dilakukan setiap kali Anda akan menggarap pengembangan fitur atau halaman baru, melakukan perbaikan kesalahan sistem (bugfix atau hotfix), maupun melakukan eksperimen teknologi baru yang belum pasti dipakai. Selain itu, branch baru juga ideal dibuat setiap kali menerima pembagian tugas spesifik saat bekerja dalam sebuah proyek kelompok.
